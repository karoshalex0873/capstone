## 📋 What You Need to Do

### Step 1: Record Your Videos

Each video should be:

- **Duration**: Exactly 20 minutes
- **Format**: MP4 (H.264 codec)
- **Quality**: 1080p or 720p recommended

### Step 2: Name Your Files

Use these EXACT names:

```
innovation_video.mp4
african_culture_video.mp4
modern_challenge_video.mp4
```

### Step 3: Add Files

Simply copy your video files into:

```

```

### Step 4: Test

- Refresh your browser
- Navigate to each video section
- Videos should play automatically!

## 💡 Pro Tips

1. **Recording Software**:
   - OBS Studio (Free, powerful)
   - Loom (Easy, browser-based)
   - Zoom (Record yourself presenting)
   - PowerPoint (Record slideshow with narration)

2. **File Size Management**:
   - 20-min 1080p ≈ 800MB-1.5GB
   - If too large, use 720p or reduce bitrate
   - Test upload to GitHub (100MB limit per file requires LFS for larger)

3. **Content Structure** (for each 20-min video):
   - Introduction: 2 minutes
   - Main content: 15 minutes
   - Conclusion: 3 minutes

4. **Testing Checklist**:
   - ✅ Video plays without stuttering
   - ✅ Audio is clear and synced
   - ✅ Duration shows correctly
   - ✅ Fullscreen works
   - ✅ Mobile responsive
